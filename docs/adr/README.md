# Architecture Decision Records

ADRs registram decisões arquiteturais relevantes, seu contexto e seus trade-offs. Use a numeração sequencial (`0001-...`) e o template em [`template.md`](template.md).

Uma mudança que contradiga um ADR aceito deve ser explicitamente registrada em um novo ADR.
