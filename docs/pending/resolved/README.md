# Pendências resolvidas

Itens `PENDING-*` fechados podem ser movidos para cá **opcionalmente**, quando
as notas de resolução forem úteis para consulta rápida.

O fluxo preferido ao concluir uma pendência é:

1. remover do índice ativo em [`../README.md`](../README.md);
2. apagar o arquivo em `docs/pending/` (o Git preserva o histórico).

Não mantenha itens `RESOLVED` no índice ativo.
